# Jev-Router 质量评测集

tasks.json 收录 30 个代表性开发任务，覆盖 8 类场景：解释、简单修复、单文件开发、
跨文件重构、架构、测试、调试、长上下文。

## 对比策略

同一批任务分别用四种策略各跑一遍：

1. 全部使用最强模型（成本与完成率基线）。
2. 全部使用最低成本模型。
3. 静态规则路由（JEV_DECISION_PROVIDER=static）。
4. Jev 动态路由（默认配置）。

## 验收指标

- 完成率相对"全用最强模型"基线的差距不超过 3 个百分点。
- 成本相对"全用最强模型"下降至少 20%。
- Jev 决策 P95 ≤ 800ms（超时 fail-open，不阻塞执行）。
- 同一回合非预期模型切换率 < 2%。
- 每个发布模型档案至少 20 个有效样本；样本不足标记"未校准"。

## 记录字段

每条任务记录：任务 id、策略、模型/provider、完成与否、返工次数、耗时、token、
估算成本、decisions.jsonl 中对应的 decisionId。评估在临时目录进行，不触碰真实仓库。
